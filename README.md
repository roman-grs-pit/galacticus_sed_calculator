# Galacticus SED Calculator

This repository contains tools for calculating galaxy spectral energy
distributions (SEDs) and broad-band magnitudes from star formation histories
saved by [Galacticus](https://github.com/galacticusorg/galacticus). Its main use
is to add photometry to Galacticus lightcone catalogs, including the lightcones
used to construct mock catalogs for the Roman Galaxy Redshift Survey.

The calculation combines the star formation and metallicity histories of each
galaxy with a stellar-population SED template generated by Galacticus.
Continuum and emission-line spectra can be calculated for disk, spheroid, or
total galaxy components. The resulting spectra can be evaluated directly or
integrated through filter transmission curves to obtain observed magnitudes.

## Installation

The package requires Python 3.10 or later. One way to create a clean conda
environment and install the package is:

```bash
conda create -n galacticus-sed python=3.12 pip
conda activate galacticus-sed
python -m pip install -e ".[scripts]"
```

Run these commands from the repository root. The `scripts` option installs
STPSF, which supplies the Roman WFI filter transmission curves. To use only the
Python SED-calculation API without the Roman catalog scripts, install with:

```bash
python -m pip install -e .
```

The current test suite is run on Python 3.10, 3.11, 3.12, and 3.13.

The reader supports both legacy and modern Galacticus emission-line metadata,
including the AGN extractor names `lmnstyEmssnLineAGN` and
`luminosityEmissionLineAGN`, and HDF5 attributes stored as text or byte strings.
Existing catalogs do not need to be converted.

## Quick Start

The repository includes a five-galaxy Galacticus lightcone and a compatible SED
template. This command calculates an F158 AB magnitude for each galaxy and
writes a compact output file:

```bash
python scripts/calculate_catalog_magnitudes.py \
  data/romanUNIT.hdf5 \
  data/nodePropertyExtractorSED_Nt50_NZ11_ageMinimum0.001.hdf5 \
  --filters F158 \
  --save-to-file example_magnitudes.hdf5
```

The output contains the magnitudes, galaxy indices, redshifts, magnitude
system, and cosmology used for the calculation. To calculate all seven Roman
WFI imaging filters, omit `--filters`:

```bash
python scripts/calculate_catalog_magnitudes.py \
  data/romanUNIT.hdf5 \
  data/nodePropertyExtractorSED_Nt50_NZ11_ageMinimum0.001.hdf5 \
  --save-to-file example_all_roman_magnitudes.hdf5
```

If `--save-to-file` is omitted, the script instead copies the input catalog,
adds the magnitude datasets to the copy, and gives it a `_with_magnitudes`
suffix; the original catalog is not modified. Pass `--no-copy` only when you
intentionally want to modify the input file in place. Use `--help` to see the
available filters, galaxy components, magnitude systems, dust options,
wavelength grid, and parallel-processing options.

## Required Inputs

The principal inputs are:

- A Galacticus lightcone or fixed-time HDF5 output containing saved disk and
  spheroid star formation histories, their age and metallicity grids, and the
  properties needed for any requested emission-line or dust calculation.
- A Galacticus `nodePropertyExtractorSED` template containing the tabulated
  mapping from stellar age and metallicity to spectral luminosity.

The age grid used for the template must match the one used to save the galaxy
star formation histories. An explanatory error is raised if they are
incompatible. The catalog magnitude command reads cosmology from
`/Parameters/cosmologyParameters` in the catalog by default; its command-line
options can override those values.

A magnitude that is not defined, for example because a galaxy has no stellar
flux in the requested band, is represented by `NaN`. A galaxy-level calculation
error is reported separately and does not prevent other galaxies from being
processed.

See [data/README.md](data/README.md) for descriptions and provenance of the
bundled example files.

## Python API

The `SEDCalculator` class can be used to inspect a galaxy and calculate its
spectrum directly:

```python
from pathlib import Path

import astropy.units as u
import numpy as np
from astropy.cosmology import LambdaCDM

from galacticus_sed_calculator import SEDCalculator

root = Path.cwd()
catalog = root / "data/romanUNIT.hdf5"
template = root / "data/nodePropertyExtractorSED_Nt50_NZ11_ageMinimum0.001.hdf5"
unit_cosmology = LambdaCDM(H0=67.74, Om0=0.3089, Ode0=0.6911)

calculator = SEDCalculator(template, cosmology=unit_cosmology)
galaxy = calculator.read_galacticus_galaxy(catalog, galIndex=0)

wavelength = np.linspace(8000, 30000, 2000) * u.AA
spectrum = calculator.evaluate_total_spectrum(
    catalog,
    galIndex=0,
    obs_wavelengths=wavelength,
)
flux_density = spectrum(wavelength, flux_unit="flam")
```

When constructing `SEDCalculator` directly, pass an Astropy cosmology matching
the simulation catalog. `read_galacticus_galaxy` and the spectrum methods
automatically recognize the standard Galacticus lightcone
(`/Lightcone/Output1`) and fixed-time (`/Outputs/OutputN`) layouts.

The notebook is a guided introduction to the main calculation. The Python
scripts are shorter, task-specific examples that can be run directly or adapted
for catalogue-processing workflows:

- [examples/exampleUsage.ipynb](examples/exampleUsage.ipynb), a worked
  notebook covering spectra, template compatibility, dust attenuation, and
  Roman WFI magnitudes;
- [examples/example_SEDs_for_lightcone.py](examples/example_SEDs_for_lightcone.py),
  an end-to-end lightcone example suitable as a starting point for grism-image
  inputs;
- [examples/example_dust_attenuation.py](examples/example_dust_attenuation.py),
  a comparison of emission-line and continuum attenuation;
- [examples/example_fast_sed.py](examples/example_fast_sed.py), a comparison of
  the adaptive and fixed-grid spectrum calculation paths;
- [examples/example_profiling.py](examples/example_profiling.py), a short
  catalogue-scale timing example.

## Dust Attenuation

The magnitude command accepts a YAML dust configuration through
`--dust-config`. Emission-line and continuum attenuation are configured
separately. For example:

```yaml
emission_line_dust:
  model: gb10_generalised
  params:
    delta_0: 0.2772
    delta_z: -1.5792
    delta_M: -0.8180
    delta_Mz: -0.5287
    attenuation_scatter: 0.25
  law: calzetti
  random_uniform_index: 0
continuum_dust:
  model: fixed_av
  params:
    A_V: 1.0
  law: calzetti
```

Example configurations are in [data/dustModel](data/dustModel). The calibrated
values in those files apply to the particular Galacticus model described there;
they are not intended as universal dust parameters.

A standalone [Benson diffuse-transfer provider](docs/BENSON_DIFFUSE.md) is also
available for disk and spheroid light passing through disk-distributed dust.
It interpolates attenuation in the checksum-verified external R_V=4 atlas and
returns transmission plus diagnostics. See
[example_benson_diffuse.py](examples/example_benson_diffuse.py) for evaluation,
timing and lightweight interpolation checks. This is the first component of
the planned `clouds_diffuse` model; it is not yet a selectable catalog/SED dust
configuration.

## Generate catalog spectra

`generate_catalog_seds.py` writes observed-frame spectra, galaxy identifiers,
source-row indices, observed redshifts where available, and metadata. With no selection cuts it processes every galaxy;
optional redshift, magnitude and property cuts select a smaller sample.

```bash
python scripts/generate_catalog_seds.py \
  input_catalog.hdf5 \
  nodePropertyExtractorSED_Nt50_NZ11_ageMinimum0.001.hdf5 \
  catalog_with_seds.hdf5 \
  --n-jobs 8 --batch-size 32 \
  --wavelength-min 4000 --wavelength-max 24000 \
  --wavelength-npoints 10001 --flux-unit flam
```

`--n-jobs` sets worker processes (default 1); `--batch-size` sets galaxies per
computation and output-write batch (default 32). Each worker initializes one
calculator and reuses it. The parent writes each completed batch to its proper
rows in HDF5, preserving catalog order. At most a bounded number of batches
are in flight, so spectra are streamed rather than accumulated for the whole
catalog. For the grid above, a batch of 32 dust-free and attenuated spectra
contains approximately 5 MB of float64 values, in addition to each worker's
template and caches. More workers are not necessarily faster if memory or
filesystem throughput is limiting. When using multiple workers, set
`OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1` in the environment
to limit numerical-library threads within each worker.

The output contains `observedSED` and `observedSEDWavelengths` in `nodeData`,
and also in `dustAttenuatedNodeData` when dust metadata are present. Add
`--dust-attenuated-only` to calculate and store only the dust-attenuated spectra.
This skips the extra dust-free calculation and spectral array, and requires
dust metadata in the catalog.
Dust scatter
uses the catalog's stored random-number index; nonzero scatter without that
index is rejected so results do not depend on worker scheduling. The default
cosmology remains `FlatLambdaCDM(H0=67.74, Om0=0.3089)`.

The default compact output keeps `nodeIndex` and `lightconeRedshiftObserved`
when available, plus `sourceRowIndices` under the output group. These are zero-based
row indices into the original catalog, whose path is stored as `sourceCatalog`.
Model parameters, dust settings, the SED template path, and the calculation
cosmology are also recorded. Other galaxy quantities can be retrieved from
the source catalog using this row mapping. Add `--copy-catalog-quantities` to
include all catalog quantities for the selected galaxies, including their
star-formation histories, in the output file.

For example, add `--redshift-min 0.5 --redshift-max 2 --magnitude-max 24
--magnitude-filter F158` to select a subset. Magnitude cuts use the dust-free
`nodeData` magnitudes. The input is read-only and existing output files are
not overwritten. Failed computations raise an error; check the output group's
`sedGenerationComplete` attribute before using an interrupted output. Choose a
new output filename to retry. Spectra with physically undefined fluxes may
still contain nonfinite values and should be checked for your application.

The historical `create_downsampled_catalog.py` command remains available with
the same options and compact-output default. Add `--copy-catalog-quantities`
to retain its historical full-catalog output.

## Other Catalog Tools

The repository also includes scripts to:

- convert Galacticus lightcone angles to right ascension and declination with
  `scripts/calculate_catalog_coordinates.py`;
- add reproducible uniform random values for stochastic galaxy properties with
  `scripts/calculate_catalog_random_numbers.py`;
- generate spectra with optional galaxy selection using
  `scripts/generate_catalog_seds.py`;
- generate diagnostic plots for Roman mock catalogs with
  `scripts/diagnostics/run_mock_catalog_diagnostics.py`.

The plotting dependencies are installed with:

```bash
python -m pip install -e ".[diagnostics]"
```

Coordinate-transformation examples are in
[docs/COORDINATE_TRANSFORMATION_GUIDE.md](docs/COORDINATE_TRANSFORMATION_GUIDE.md),
and profiling tools are described in [docs/PROFILING.md](docs/PROFILING.md).

## Development

Install the test dependencies and run the complete suite with:

```bash
python -m pip install -e ".[dev]"
python -m pytest
```

GitHub Actions runs the tests on each supported Python version and performs a
one-galaxy Roman magnitude calculation using the bundled lightcone. Exact
direct-dependency versions from one clean verification run are recorded in
[docs/TESTED_ENVIRONMENT.md](docs/TESTED_ENVIRONMENT.md).
